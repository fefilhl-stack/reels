# Relay — главная страница

Тёмный лендинг с лаймовым акцентом по мотивам ролика: светящиеся «волокна» на фоне,
стеклянные карточки, интро с лаймовой плиткой и секции, которые оживают при скролле.

Чистые HTML + CSS + JS, без сборки и зависимостей. Шрифты лежат в репозитории,
внешних запросов страница не делает.

## Как открыть

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно и просто открыть `index.html` двойным кликом, но через сервер надёжнее
(часть браузеров ограничивает `file://`).

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → ветка и папка `/ (root)`.
Через минуту сайт появится по адресу `https://<user>.github.io/<repo>/`.
Подойдёт и любой статический хостинг: Netlify, Vercel, Cloudflare Pages.

## Что на странице

1. **Интро** — линия обегает экран, лайм заливает его, сжимается в плитку, и плитка
   «садится» на первый узел схемы в первом экране.
2. **Первый экран** — заголовок, кнопки и живая карточка воркфлоу: импульсы бегут
   по связям, список «last runs» пополняется сам.
3. **Интеграции** — ряд приложений, подсветка переходит от одного к другому.
4. **Most of a process is glue** — три фичи: таймлайн прогона, одобрение в Slack
   (кнопки нажимаются), изометрические столбики.
5. **Манифест** — лаймовая панель на скролле разворачивается на весь экран,
   слова проявляются по одному, потом панель сжимается в плитку с логотипом.
6. **Reliability** — хаб «один рантайм» и регионы.
7. **Daily view** — дашборд: неделя, кольцо 82 %, аватары, волны, регионы.
8. **Case studies** — счётчики, графики, цитаты.
9. **Pricing** — слайдер оценки (логарифмический, 3 000–300 000 прогонов),
   подсвечивает подходящий тариф.
10. **CTA и футер.**

Фон — WebGL (`assets/js/ribbons.js`): пучок тонких волокон с яркой точкой фокуса.
У каждой секции свой рисунок пучка (атрибут `data-scene`), при скролле формы плавно
перетекают друг в друга, пучок реагирует на мышь и скорость прокрутки. Если WebGL
недоступен, включается мягкий градиент. При `prefers-reduced-motion` интро и
анимации отключаются, фон рисуется статичным кадром.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты, разделы, тарифы | `index.html` |
| Цвета, шрифты, отступы | `assets/css/styles.css`, переменные в `:root` (`--lime`, `--bg`, …) |
| Интро, счётчики, слайдер, анимации | `assets/js/main.js` |
| Форма и цвет фоновых волокон | `assets/js/ribbons.js`, объект `SCENES` и цвета в шейдере |
| Логотип | символ `#i-relay` в начале `index.html` и `assets/img/favicon.svg` |

Цены и границы тарифов для слайдера заданы в `main.js` (объект `PLANS`): если меняете
тарифы в разметке, поправьте и его.
