# Relay и ТУРБО — главные страницы

Лендинг по мотивам ролика: тёмная тема, лаймовый акцент, светящиеся волокна на фоне,
стеклянные карточки и секции, которые оживают при прокрутке.

В проекте две страницы на одном движке:

- `/` — **Relay**, исходный лендинг из ролика (английский);
- `/turbo/` — **ТУРБО**, главная для [turbosolution.ru](https://turbosolution.ru/) на русском:
  тот же дизайн и анимации, контент адаптирован под платформу ТУРБО X и её решения.

И отдельно третья, без сборки:

- `/planet/` — **ТУРБО с планетой**: главная ТУРБО одним файлом `public/planet/index.html`
  поверх WebGL-Земли (подробнее в разделе «Страница с планетой»).

Стек: **Next.js 16** (App Router, TypeScript), **three.js** для фона и изометрических
столбиков, **Lenis** для плавной прокрутки. Сайт собирается в статику: на выходе обычные
HTML/CSS/JS в папке `out/`, сервер не нужен.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run build      # сборка статики в out/
npm run preview    # посмотреть собранную версию: http://localhost:3000
```

Открыть `out/index.html` двойным кликом не получится: пути к файлам в сборке абсолютные,
нужен любой статический сервер (`npm run preview`, `npx serve out`, `python3 -m http.server`
из папки `out`).

### Версия «открыть с рабочего стола»

```bash
npm run build:desktop
```

Создаёт папки `desktop-build/Relay/` и `desktop-build/Turbo/`, в каждой один файл
`index.html`, в который встроено всё: скрипты, стили, шрифты, иконка. Папку можно
скопировать куда угодно, сайт открывается двойным кликом по `index.html`, без сервера и
без интернета. Это те же страницы, только собранные без сервера Next.js (точки входа —
`desktop/main.tsx` и `desktop/turbo.tsx`, скрипт — `scripts/build-desktop.mjs`).
Собрать только одну: `npm run build:desktop -- turbo`.

## Публикация

- **Vercel / Netlify / Cloudflare Pages**: подключить репозиторий, команда сборки
  `npm run build`, папка с результатом `out`.
- **GitHub Pages**: если сайт живёт по адресу вида `https://<user>.github.io/<repo>/`,
  собирать с базовым путём:

  ```bash
  NEXT_PUBLIC_BASE_PATH=/<repo> npm run build
  ```

  и выложить содержимое `out/` (например, через GitHub Actions или в ветку `gh-pages`).
  Пустой файл `.nojekyll` уже попадает в сборку из `public/`, без него GitHub не отдал бы папку `_next`.

## Что на странице

1. **Заставка.** Лаймовый экран с логотипом сжимается в скруглённую плитку, летит к первому
   узлу схемы в первом экране и становится тонкой лаймовой рамкой. Пока экран лаймовый,
   в фоне компилируются шейдеры, поэтому на медленных устройствах анимация не дёргается.
2. **Первый экран.** Заголовок, печатающиеся подписи и 3D-карточка воркфлоу: наклоняется
   за мышью, по связям бегут импульсы, список «last runs» пополняется сам.
3. **Интеграции.** Ряд приложений, лаймовая точка перебегает по пунктиру от одного к другому.
4. **Most of a process is glue.** Таймлайн запуска со счётчиками миллисекунд, карточка
   Slack (кнопки Approve/Hold нажимаются), изометрические столбики на three.js: плашки падают
   сверху и наращивают столбцы.
5. **Манифест.** Лаймовая плитка поднимается, разворачивается в широкую полосу, фраза
   проявляется по словам, потом всё складывается в лаймовую рамку вокруг логотипа.
6. **Reliability.** Хаб «один рантайм» с бегущими точками и регионы с ползунками.
7. **Daily view.** Тепловая карта недели, кольцо 81 %, аватары, волны отказов и
   восстановлений, точечная карта мира с пульсом во Франкфурте.
8. **Case studies.** Счётчики, спарклайн, столбики, полоса прогресса и цитаты.
9. **Pricing.** Ползунок с логарифмической шкалой (3 000 – 600 000 запусков) сам подбирает
   тариф; три карточки тарифов.
10. **Финал и подвал.** Карточка бренда, лаймовая форма «Pick the task you hate most»
    с проверкой email, статусы и ссылки.

## Страница ТУРБО

Те же блоки, что у Relay, с русским контентом: продукты (ТУРБО X, ERP, Бюджетирование,
ТОРО, Имущественный комплекс, Отель, WMS), платформа, надёжность, рабочий день, клиенты
(ВТБ, АШАН, Райффайзенбанк), форматы внедрения вместо тарифов (цен на сайте нет, ползунок
подбирает формат по числу пользователей), форма «Запросить демо», контакты и ссылки на
разделы turbosolution.ru.

Факты о компании взяты с turbosolution.ru. Цифры в демо-карточках (миллисекунды, суммы,
проценты, имена в чате) иллюстративные, как в макете Relay. Логотип ТУРБО не копировался:
знак в плитке — простой «Т» с линиями скорости (`TurboMark` в `components/ui/Icons.tsx`),
его легко заменить настоящим. Курсив набран Playfair Display: в Instrument Serif нет кириллицы.

Под секциями 4–8 фон размыт: это один фиксированный слой с `backdrop-filter`, обрезанный
по видимой части этих секций. В первом экране, интеграциях и ценах волокна резкие, как в ролике.

Учтено:

- при `prefers-reduced-motion` анимации выключены, фон рисуется одним кадром;
- без WebGL вместо волокон мягкий градиент;
- если скрипты не загрузились, через 10 секунд страница показывается без анимаций;
- на телефонах карточки перестраиваются в колонку, схема в первом экране не наклоняется.

## Страница с планетой

`public/planet/index.html` — самостоятельная страница в одном файле: HTML, CSS и JS внутри,
без сборки и без фреймворка. Её можно открыть двойным кликом, а при `npm run build` она
попадает в `out/planet/index.html` и публикуется вместе с сайтом по адресу `/planet/`.

Сделана по техзаданию «Ascend — Scale Smarter, Not Harder» (макет SaaS-лендинга с планетой),
тексты заменены на русские про ТУРБО. Четыре стеклянные секции лежат поверх фиксированной
WebGL-сцены:

1. **Первый экран.** «Бизнес-системы без тормозов», кнопки «Запросить демо» и «Смотреть
   продукты», ряд клиентов (ВТБ, АШАН, Райффайзенбанк, Ростелеком, Ингосстрах, Gorenje).
   Огромная Земля всплывает снизу, когда загрузятся модели.
2. **Продукты.** Шесть карточек: ТУРБО ERP, Бюджетирование, ТУРБО Отель, платформа ТУРБО X,
   ТУРБО ТОРО, Имущественный комплекс.
3. **Платформа.** Текст про ТУРБО X и OLAP in-memory, макет панели «Закупки · III кв.»
   с растущими столбиками и полосами, четыре цифры: годы с 1991-го (считаются от текущего
   года), 1000+ клиентов, 50+ отраслевых решений партнёров, 100 % российская разработка.
4. **Финал и подвал.** «Выведите бизнес на новую орбиту», кнопки «Запросить демо» (письмо на
   info@turbosolution.ru) и телефон, ссылки на разделы turbosolution.ru, год в копирайте
   подставляется сам.

При прокрутке планета отъезжает влево, потом вправо и останавливается за финальной карточкой,
поворачиваясь на ходу. Плавная прокрутка через Lenis, секции проявляются по очереди.

Что подгружается из интернета (без сети страница остаётся читаемой, но без планеты):

- three.js r0.143.0 через importmap с unpkg.com (шейдеры рассчитаны именно на эту версию
  и `WebGL1Renderer`), Lenis 1.3.23 с unpkg.com, шрифт Inter с Google Fonts;
- модели и текстуры планеты (`planet.glb`, `planet-lights.glb`, `planet-clouds.png`) из бакета
  `api.getlayers.ai`, декодер DRACO с www.gstatic.com.

Учтено:

- при `prefers-reduced-motion` секции видны сразу, Lenis и всплытие планеты выключены;
- если WebGL недоступен или модели не загрузились, остаётся тёмный фон, текст на месте;
- если не загрузился Lenis, прокрутка обычная, ссылки по разделам работают;
- плотность пикселей сцены ограничена 2×: три цепочки постобработки на 3× слишком тяжёлые.

Где что менять: тексты — прямо в разметке; цвета и сетка — переменные в `:root`; параметры
сцены — объект `CONFIG`; траектория планеты при прокрутке — `STOPS_X`, `STOPS_Y`, `STOPS_S`;
какой слой рисует какой объект — `DRAW`.

Цифры в макете панели (столбики, проценты) иллюстративные. Знак ▲ в логотипе — из макета,
настоящий логотип ТУРБО не копировался.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты секций Relay | `components/sections/*.tsx` (по файлу на секцию) |
| Тексты страницы ТУРБО | `components/turbo/*.tsx` и `components/turbo/content.ts` |
| Цвета, шрифты, общие стили | `app/globals.css`, переменные в `:root` (`--lime`, `--bg`, …) |
| Стили конкретной секции | соседний `*.module.css` |
| Русло «реки» из волокон по секциям, её ширина и цвет | `lib/ribbons.ts`, объект `RIVER` и функция `palette` в шейдере |
| Столбики «runs per weekday» | `lib/isoBars.ts` и `components/sections/IsoBarsCard.tsx` (`VALUES`) |
| Заставка | `components/Intro.tsx` |
| Тарифы и логика ползунка | `components/sections/Pricing.tsx` (`PLANS`, `MIN`, `MAX`) |
| Логотип | `components/ui/Icons.tsx` (`Chevrons`, `TurboMark`) и `icon.svg` рядом с layout |
| Заголовок и описание страницы | `app/(relay)/layout.tsx` и `app/(turbo)/turbo/layout.tsx` (`metadata`) |
| Страница с планетой: тексты, стили, сцена | `public/planet/index.html` (`CONFIG`, `STOPS_*`, `DRAW`) |

Формы email сейчас только показывают подтверждение. Чтобы письма куда-то уходили,
подключите обработчик в `components/sections/FinalCta.tsx` и `components/turbo/Demo.tsx`
(функция `submit`).

## Структура

```
app/
  (relay)/               layout, page и иконка Relay (адрес /)
  (turbo)/turbo/         layout, page и иконка ТУРБО (адрес /turbo/)
  globals.css, page.module.css
  fonts/                 Instrument Serif Italic, Playfair Display Italic (SIL OFL)
components/
  Intro, Header, Ribbons, FrostLayer, Cursor, SmoothScroll, RevealObserver
  sections/              по компоненту на секцию + их стили (Relay)
  turbo/                 секции ТУРБО на тех же стилях + content.ts
  ui/                    Typewriter, RollingNumber, SectionHead, Avatar, Icons
lib/
  ribbons.ts             фон на three.js: «река» из волокон, пыль, боке
  isoBars.ts             изометрические столбики на three.js
  world.ts               контуры материков для точечной карты
  hooks.ts, motion.ts    видимость, счётчики, плавности
public/
  planet/index.html      страница ТУРБО с WebGL-планетой, один файл без сборки (адрес /planet/)
```

Шрифты: Geist и Geist Mono из пакета `geist`, Instrument Serif и Playfair Display лежат
в `app/fonts`.
