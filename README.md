# Relay — главная страница

Лендинг по мотивам ролика: тёмная тема, лаймовый акцент, светящиеся волокна на фоне,
стеклянные карточки и секции, которые оживают при прокрутке.

Стек: **Next.js 16** (App Router, TypeScript), **three.js** для фона и изометрических
столбиков, **Lenis** для плавной прокрутки. Сайт собирается в статику: на выходе обычные
HTML/CSS/JS в папке `out/`, сервер не нужен.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run build      # сборка статики в out/
npm run preview    # посмотреть собранную версию: http://localhost:3000
```

Открыть `out/index.html` двойным кликом не получится: пути к файлам в сборке абсолютные,
нужен любой статический сервер (`npm run preview`, `npx serve out`, `python3 -m http.server`
из папки `out`).

## Публикация

- **Vercel / Netlify / Cloudflare Pages**: подключить репозиторий, команда сборки
  `npm run build`, папка с результатом `out`.
- **GitHub Pages**: если сайт живёт по адресу вида `https://<user>.github.io/<repo>/`,
  собирать с базовым путём:

  ```bash
  NEXT_PUBLIC_BASE_PATH=/<repo> npm run build
  ```

  и выложить содержимое `out/` (например, через GitHub Actions или в ветку `gh-pages`).
  Пустой файл `.nojekyll` уже попадает в сборку из `public/`, без него GitHub не отдал бы папку `_next`.

## Что на странице

1. **Заставка.** Лаймовый экран с логотипом сжимается в скруглённую плитку, летит к первому
   узлу схемы в первом экране и становится тонкой лаймовой рамкой. Пока экран лаймовый,
   в фоне компилируются шейдеры, поэтому на медленных устройствах анимация не дёргается.
2. **Первый экран.** Заголовок, печатающиеся подписи и 3D-карточка воркфлоу: наклоняется
   за мышью, по связям бегут импульсы, список «last runs» пополняется сам.
3. **Интеграции.** Ряд приложений, лаймовая точка перебегает по пунктиру от одного к другому.
4. **Most of a process is glue.** Таймлайн запуска со счётчиками миллисекунд, карточка
   Slack (кнопки Approve/Hold нажимаются), изометрические столбики на three.js: плашки падают
   сверху и наращивают столбцы.
5. **Манифест.** Лаймовая плитка поднимается, разворачивается в широкую полосу, фраза
   проявляется по словам, потом всё складывается в лаймовую рамку вокруг логотипа.
6. **Reliability.** Хаб «один рантайм» с бегущими точками и регионы с ползунками.
7. **Daily view.** Тепловая карта недели, кольцо 81 %, аватары, волны отказов и
   восстановлений, точечная карта мира с пульсом во Франкфурте.
8. **Case studies.** Счётчики, спарклайн, столбики, полоса прогресса и цитаты.
9. **Pricing.** Ползунок с логарифмической шкалой (3 000 – 600 000 запусков) сам подбирает
   тариф; три карточки тарифов.
10. **Финал и подвал.** Карточка бренда, лаймовая форма «Pick the task you hate most»
    с проверкой email, статусы и ссылки.

Под секциями 4–8 фон размыт: это один фиксированный слой с `backdrop-filter`, обрезанный
по видимой части этих секций. В первом экране, интеграциях и ценах волокна резкие, как в ролике.

Учтено:

- при `prefers-reduced-motion` анимации выключены, фон рисуется одним кадром;
- без WebGL вместо волокон мягкий градиент;
- если скрипты не загрузились, через 10 секунд страница показывается без анимаций;
- на телефонах карточки перестраиваются в колонку, схема в первом экране не наклоняется.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты секций | `components/sections/*.tsx` (по файлу на секцию) |
| Цвета, шрифты, общие стили | `app/globals.css`, переменные в `:root` (`--lime`, `--bg`, …) |
| Стили конкретной секции | соседний `*.module.css` |
| Форма и цвет волокон, сцены по секциям | `lib/ribbons.ts`, объект `SCENES` и функция `palette` в шейдере |
| Столбики «runs per weekday» | `lib/isoBars.ts` и `components/sections/IsoBarsCard.tsx` (`VALUES`) |
| Заставка | `components/Intro.tsx` |
| Тарифы и логика ползунка | `components/sections/Pricing.tsx` (`PLANS`, `MIN`, `MAX`) |
| Логотип | `components/ui/Icons.tsx` (`Chevrons`) и `app/icon.svg` |
| Заголовок и описание страницы | `app/layout.tsx` (`metadata`) |

Форма email сейчас только показывает подтверждение. Чтобы письма куда-то уходили,
подключите обработчик в `components/sections/FinalCta.tsx` (функция `submit`).

## Структура

```
app/
  layout.tsx, page.tsx, globals.css, icon.svg
  fonts/                 Instrument Serif Italic (SIL OFL)
components/
  Intro, Header, Ribbons, FrostLayer, Cursor, SmoothScroll, RevealObserver
  sections/              по компоненту на секцию + их стили
  ui/                    Typewriter, RollingNumber, SectionHead, Avatar, Icons
lib/
  ribbons.ts             фон на three.js (шейдеры, сцены, пыль, боке)
  isoBars.ts             изометрические столбики на three.js
  world.ts               контуры материков для точечной карты
  hooks.ts, motion.ts    видимость, счётчики, плавности
```

Шрифты: Geist и Geist Mono из пакета `geist`, Instrument Serif лежит в `app/fonts`.
